# Changelog

## 0.1.0

Initial release.

- `login` / `logout` — connect to a Solidtime instance
- `where` — show current context
- `project list/create/update` — manage projects
- `time-entry list/start/stop/create/update/delete` — manage time entries (alias: `te`)
- `task list/create/update/delete` — manage tasks
- `tag list/create/update/delete` — manage tags
- `member list` — list organization members
- `account list/use/show/remove` — multi-account management
- `organization list/use` — switch organizations
- `discover context/projects/tasks/tags/members` — AI-first discovery
- `profile` — show current user
- `upgrade` — self-update from GitHub releases
- `completion bash/zsh/fish` — shell autocompletion
- Global flags: `--json`, `--compact`, `--dry-run`, `--no-interactive`
